规则#1：纽约时间唯一制
目标
凡涉及“哪一天”（如：今天 / 昨天 / 收盘日 / 评估日 / 日度键），一律以纽约“交易日”为准，统一写作 YYYY-MM-DD。
适用范围
算法、接口、存储、缓存键名、日志字段、导入导出、页面展示、报表与诊断等所有出现“哪一天”的地方。
必须遵守
统一入口：把“具体时刻 → 哪一天”的换算，必须经过同一套口径/同一入口；任何位置不得各自推导。
统一表示：所有“日”的传递与存储只使用纽约日字符串 YYYY-MM-DD，不得用 Date/ISO 充当“日”。
交易日口径：判定“哪一天”以纽约交易日为准（09:30 开盘、16:00 收盘、节假日表），不是 00:00–24:00 的日历日。
先归一再使用：第三方数据（无论按 UTC 或其他时区给“当日/收盘”），先换成纽约这一天再计算/存储/展示。
跨端一致：同一“纽约时刻”，在纽约/伦敦/北京/服务器等环境的换算结果必须一致。
禁止事项（出现即违规）
以本机或 UTC 直接截日期（如：toISOString().slice(0,10)、toLocaleDateString()、new Date('YYYY-MM-DD') 等同类做法）。
手工加减小时、手写 -05:00 / -04:00 等“补差”。
对同一时刻进行二次时区转换/重复校正（例如“先按纽约处理，后又再转一次时区”）。
绕开统一入口，在任何位置自行计算“今天/昨天/交易日”。
验收口径（全部需满足）
四环境一致：以“纽约 2025-10-06 22:30”为样例，在纽约/伦敦/北京/服务器四处换算出的“哪一天”均为 2025-10-06。
边界正确：09:29:59/09:30:00 与 15:59:59/16:00:00 的判定符合交易日规则，不跑偏。
DST 稳定：夏令时进入/退出当周的样例换算不偏移日期。
节假日一致：按交易日表返回一致结果，不被 UTC 推前/推后。
统一表示：所有“日”的键名/字段/展示均为 YYYY-MM-DD，不存在用 Date/ISO 代表“日”的情况。
违规处理
命中任一“禁止事项”或不满足任一“验收口径”，视为违规；需整改至全部满足为止。

规则#2
全局规则｜功能区1独立计算与来源锁死
范围：页面「功能区1」内的全部 M 指标。
目标：每个指标独立、只用我导入的数据计算，任何缓存/打包/兜底与网络数据不得干扰。
规则A｜模块独立（Rule #2 固化）
功能区所有 M 模块各自独立计算，不得引用其他模块的中间产物。
同一指标的 LIVE / CLOSE / DEGRADED 仅影响取价来源，不改变公式。
任一 M 模块出错/缺数，只影响该模块本身的显示与结果，不得级联影响其他模块。
规则B｜三类输入与来源锁死（import_strict）
功能区1仅允许三类输入，来源固定如下：
实时价格（Realtime）
获取途径：参与所需要的算法
数据来源：只允许读取于“功能区2”的实时价格栏的数值
收盘价格（Official Close）
唯一来源：我导入的 close_prices（JSON），写入本地库后参与计算。
允许的来源标记：official/import（含历史别名 import）、official/manual。
禁止的一切来源：official/packaged、任意“兜底/均价/沿用上一日/最新价当昨收/lastKnown/fallback/realtimeAsClose”等路径。
交易记录（Trades）
唯一来源：我导入的成交明细（JSON），写入本地库后参与计算。
允许的来源标记：trades/import、trades/manual。
禁止的一切来源：trades/server、broker/*、trades/packaged、任何“推断/重建”的伪交易。
判定冲突时：同级后写覆盖先写（以写入时间/更新时间为准）；版本号仅用于触发重算，不参与胜出判断。
规则C｜缺失与退化（SAFE 严格）
在允许来源集合中找不到所需 (date, symbol) 的收盘价或交易时，直接判缺并提示；确实的具体内容
严禁以打包、兜底、网络或任何被禁来源回落替代；
DEGRADED 亦不得改变公式或引入兜底，只能如实标注不可用/不完整。
规则D｜导入后的强制重算（防“缓存假干扰”）
导入收盘价或交易记录并成功写入本地库后，必须立即触发功能区1重算（失效标记 + 重算事件）。
该触发与是否向服务器写回成功无关，不可被跳过。
任何内存态/缓存态结果不得跨越新的导入版本继续沿用。
规则E｜错误隔离与显示
单个 M 模块缺失或异常时：只在该模块标注“缺数据/不可用”；其他 M 模块照常按自身可得数据计算。
严禁“为通过展示”而引入临时兜底或跨模块借数。
规则F｜验收要点（自检）
功能区1内的任意结果，仅来自：我导入的收盘价 + 我导入的交易+功能区2“实时价格”一栏的数值；
日志/诊断中，收盘价来源只应出现 official/import|import|official/manual；交易只应出现 trades/import|trades/manual；出现 packaged/server/fallback 即为违规；
删除导入数据或换一份不含某日/某标的的数据后，该 M 应立即报缺，不得回落到任何兜底。
